# Game design v0.11

Understand Requirement → Design → Predict → Simulate → Compare → Defend. Three missions move from same-bandwidth arithmetic to WDM thermal/loss trade-offs and finally customer-specific 1.6T choice. Mission19 shows WDM as Preview; Mission20 opens λ/MUX/Tuning controls. Mission21 has Density, Power and Thermal Orders. Presets are starting points, not free PASS solutions: geometry and budgets still require decisions.

Optional prediction changes no physics. Three progressive hints show direction, metrics, then a controlled experiment. Debrief names actual failed constraints and explains modeled factors. Same-customer A/B supports controlled or multifactor interpretation, not an invented overall ranking. Mission21 review selects an observed PASS metric, a real modeled trade-off, and recomputation if requirements change. Decision Note is user-authored; Markdown report includes exact full-precision result/provenance.

First-clear rewards only once, sequential Chapter7 Campaign gates, Free Exploration immediate access with zero rewards. Mission clear is distinct from comparative engineering performance. Replay by customer/order/temperature, tuning, routing or spatial/rate mix. No CAD, PIC layout editor, cloud solver, API or external dependency introduced.
