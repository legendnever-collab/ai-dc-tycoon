기존 Chapter01/02 Inventory와 Tech Tree는 변경하지 않았습니다. Chapter03 Unlock은 검증된 First Clear Receipt로부터 계산합니다. XP와 Credits 자체가 Physical Link Rate나 Power를 바꾸지 않습니다.

New Package Blueprint는 기존 Compact/Wide Region을 선택해 재설계할 수 있게 합니다. Laser·Modulator Blueprint는 다음 Chapter의 Preview Unlock이며 세부 Guided Device 설계는 아직 잠겨 있습니다. 기존 Advanced Lab에는 보존된 자유 설계 기능이 있습니다.

모든 Clear 보상은 1회만 지급합니다. Replay 결과는 Best Stars만 갱신하며 새로운 Receipt를 생성하지 않습니다. Refund는 현재 Package Component Cost만 회복하고 Reward Receipt는 제거하지 않습니다.

기존 실제 Fixture: Chapter01 완료 340 Credits / 500 XP, Chapter02 비용·보상 포함 490 Credits / 1240 XP. Chapter03 전체 최초 Clear와 300 Credits의 장착 Package 포함 결과는 830 Credits / 2520 XP입니다. 이 값은 Source Transition 기반 Fixture에서 검증했으며 초기값을 새로 추정하지 않았습니다.

상단 Campaign Wallet과 Chapter03 모든 Scale View는 동일한 전체 Ledger를 표시합니다. 보존된 Chapter01/02 화면은 기존 Chapter별 Economy UI를 유지합니다. 새로운 물리 성능은 선택·장착된 Component에서만 계산됩니다.
