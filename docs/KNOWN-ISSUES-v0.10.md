# Known Issues / Boundaries

- Physics/presets remain the uncalibrated Educational Assumption models from v0.9. No vendor yield, full-wave EM, Evanescent CMT, warpage, reliability lifetime, BER/eye or physical OE conversion is modeled.
- Illustrative schematic coordinates are not CAD geometry. Large offset drawings clip display range while retaining full input and numerical calculations.
- Seed-reconstructible Monte Carlo samples are excluded from snapshot storage. Restoring a design retains the verified numerical summary; Run Simulation redraws sample distributions.
- Campaign and Practice/A-B storage are independent. Combined experiment restore validates both before applying but does not provide a cross-database journal; CAS protects each head independently.
- Browser-origin/profile changes, private mode and browser storage eviction can limit automatic restore. Text Backup is the portable path; no upload is needed.
- Desktop Chromium and 390/320 touch emulation are the automated acceptance environments. Physical Android, Safari/Firefox and human learning outcomes have not been tested.
- Current Mission07 PASS includes the preserved two-customer-order record requirement; comparisons with different cumulative order contexts intentionally restrict ranking.
- No numerical-model defect was corrected or new physics introduced in this release.
