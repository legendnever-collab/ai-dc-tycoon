# Engineering Decision Lab

Learning loop: Choose → Simulate → Diagnose → Save A → Change one decision → Simulate → Save B → Compare → Understand.

The Campaign keeps sequential rewards and unlocks. Free Exploration supplies direct Mission access and isolated experimentation. The interface starts with the Mission, a state-bound schematic and Engineering Decisions. The result identifies satisfied/failed hard constraints, then presents a concise three-part Debrief. Comparison details appear only when the player chooses Compare.

Four headline KPIs expose trade-offs; Engineering Details exposes other values, reference scopes and all objectives. Mission18 prioritizes Accepted Good, Cost per Accepted Unit, Manufacturing Time and Simulated Acceptance. A lower cost is not an automatic winning design if it fails a customer gate. The player chooses; the game offers bounded experiments rather than an optimum parameter recipe.

Restore Design is independent of Reset Current Experiment and Reset Comparison. Latest/Previous own full input provenance, so changing inputs does not disguise a historical PASS as a current PASS. Engineering action buttons focus supported controls without silently changing them. Unknown results remain visible as Unknown / Not Modeled.

No new Chapter, technology tree node, clear objective or reward is added.
