# Dynamic Engineering Scenes

Original premium dark dashboard, cyan/green/amber accents, embedded offline Korean font, Mission navigation and original Campaign UI are preserved.

| Family | State binding | Boundary |
|---|---|---|
| Compute / Workload | Actual Rack count; original DC time, capacity, bottleneck, waiting output | Synthetic WU; pending results stay Unknown |
| Network / Topology | Original typed Graph nodes, ports, modules and active/inactive links | Incompatible Fiber is inactive |
| CPO / Package | Actual selected architecture and original typed package connections | ELS presence differs from CW path |
| Optical / Substrate | Original Workshop graph segments, result loss ledger, Gaussian channel coordinates and computed worst channel | Diagram pixel lengths do not calculate loss; offsets magnified/clipped |
| Assembly / Manufacturing | Existing Chapter6 renderers, real seed runs and event batch ledger | Unchanged scatter, channel map and production flow |

Native SVG/HTML/CSS only. Input controls update schematic presence/connectivity/geometry. Result colors and worst-channel highlighting use current validated result; historical stale results do not color the current scene. Mobile stacks A/B cards and KPIs at 390 and 320px, with ≥44px actions and no page overflow. Reduced motion is retained. Runtime does not request network images/fonts.

Release screenshots are captured from the built offline HTML through Playwright. They are actual rendered gameplay, not mockups or ImageGen.
