# Known issues / limits v0.11

- Physical Android, Firefox/Safari and human learning effectiveness: NOT TESTED. Chromium touch emulation at320/390px is not a physical-device claim.
- Browser file:// origin/storage/clipboard policies vary. Clipboard failure exposes selectable Markdown; use explicit text backups before moving files/profiles.
- Chapter7 and older Campaign/Experiment stores have separate backups. Moving all progress requires both sets; no destructive migration or silent reset.
- Chapter7 supplemental reward wallet preserves the original wallet ledger. Combined totals appear in Chapter7 API/reward context; historical Chapter1–6 wallet display retains its original scope.
- Numerical presets, signaling indices, loss allowance, thermal transfer function and cost are uncalibrated Educational Assumptions. This release does not validate real200G/lane BER or hardware compatibility.
- Optical source W is assumed source DC electrical power. End-to-end loss stops at far-side DEMUX output and excludes unmodeled fiber attenuation/Rx. Rendering is schematic, not mechanical geometry.
- Best architecture depends on selected assumptions and constraints; no global ranking or hardware qualification is asserted.
