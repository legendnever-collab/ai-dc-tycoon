# Learning content v0.11

Terms in English, guidance in Korean. Spatial Path is a physical optical route; Wavelength is a per-path spectral channel. Per-λ Optical I/O count is not FAU path count. Gross800G can be16×1×50G,8×1×100G or4×4×50G. Payload atη=.94 is752G once, not800G. Gross1.6T can be16×100G,8×200G,8×2λ×100G or4×4λ×100G.

Prediction alternatives: fewer physical paths with higher signaling demand; same bandwidth means same power (test misconception); WDM always wins regardless of temperature (test misconception). Debrief explains actual counts and model power/reserve. Hints do not reveal all optimal parameter values. Decision Review is supported reflection, not an objective assessment of real hardware qualification.

Loss Reserve means declared modeled allowance minus loss, not Rx sensitivity margin. Tuning lowers modeled residual drift but adds watts. I/O space, routing footprint, density and cost are separate quantities. Two-row FAU reduces row span but does not automatically reduce total routing footprint or guarantee manufacturability. See model document for every equation/assumption and Not Modeled limits.
