# Game Design — v0.7

AI Workload → Network → Pluggable → CPO Package → Optical Engine → Photonic Substrate의 학습 흐름을 유지합니다. 기존 Chapter1–4와 original Advanced Lab은 보존된 entry point에서 그대로 재생성합니다.

새 Gameplay는 interface 선택, 연결, guided FAU alignment, 4/8/16-channel fixture 비교입니다. Live Candidate로 선택 효과를 확인하되 Run Simulation만 Mission Clear와 Reward Receipt를 생성합니다. Failure hint는 첫 미충족 목표와 worst-channel inspector로 연결됩니다.

Mission13은 PS input virtual meter에서 종료합니다. Mission14부터 propagation, bend, crossing, FAU coupling/alignment와 외부 fiber를 포함합니다. Mission15는 16×50G/800G, 모든 channel margin, loss, diagnostic power와 envelope를 검증합니다.

최초 Clear reward: M13 250XP/120Credits, M14 300XP/150Credits, M15 450XP/200Credits. Replay는 Best Stars를 갱신하고 중복 보상을 지급하지 않습니다.

XP/Cost는 game accounting이며 physical performance를 개선하지 않습니다. Substrate power는 diagnostic boundary로 표시하고 기존96W Package ledger에 더하지 않습니다. CPO Data Center capacity/time는 원래 모델로 유지합니다.

Chapter6는 preview이고 Advanced Coupling Workshop unlock은 현재 alignment/fixture model의 parameter exploration을 엽니다.
