# GAME DESIGN — The CPO Revolution

Game-first Chapter 3은 기존 AI Factory를 유지하면서 관심 대상을 Switch Package 안으로 옮깁니다. Mission → Experiment → Result → Reward → Unlock을 반복하며 각 Mission 3–5분을 목표로 설계했습니다. 실제 사람의 플레이 시간은 측정하지 않았습니다.

Mission07은 서로 다른 두 Customer Order로 시작합니다. 현장 교체·Cost를 중시하는 고객과 Bandwidth Density·Power를 중시하는 고객을 같은 Nominal Rate / Throughput / Traffic에서 비교합니다. 처음 보이는 KPI는 Bandwidth와 Power 두 개입니다. Cost / Density / Serviceability / 전력 Ledger는 추가 분석에서 봅니다. CPO 선택에 따른 자동 Job Time Bonus는 없습니다.

Mission08은 한 단계에 1–2개의 새 개념을 보여 줍니다. ASIC/OE의 전기 데이터, ELS의 CW Light, OE/FAU의 Optical Data가 서로 다른 색과 Typed Port로 나타납니다. 부품 배치와 연결 즉시 KPI와 Package 그림이 변합니다. 화면 Pixel 이동이 아닌 물리 mm 배치가 Electrical Reach 가정에 연결됩니다. Optical Loss는 배치에 따라 감소하지 않습니다.

Mission09는 별도의 가짜 Package를 만들지 않고 Mission08의 두 OE Prototype을 네 OE로 확장합니다. 호환 Tx/Rx와 Laser Supply가 준비된 Switch를 AI Factory에 설치해야 Network Link가 활성화됩니다. 설치 모습, Traffic Animation, Simulation Objective, 별점, Component Reward Reveal과 Workshop Preview가 다음 Chapter로 이어집니다.

실패는 장비/경로의 상태와 쉬운 한국어 Diagnosis로 안내합니다. Retry는 Assembly를 유지하고 Refund는 현재 장비 비용을 회복합니다. 별점은 최적화 기록이며 다음 Mission 진입은 Clear 자체로 결정됩니다. Reward Receipt는 실제 Simulation 입력/결과 Hash를 검증하고 중복 지급을 막습니다.

Desktop Slot 클릭과 Mobile Guided Button은 동일한 Command를 보냅니다. 최소 44px 버튼, 320px 폭, 쉬운 상위 World 이동, Reduced Motion을 지원합니다. 전체 Graph Compiler나 Physics Inspector는 필수 학습 요소가 아닙니다.

UX Design Review / 자동 Browser Review는 수행했습니다. 실제 초보자 대상 Usability Study, Android 실기기, 전체 Accessibility Audit는 NOT TESTED입니다. 지원되지 않는 Future Save는 정상 진행처럼 표시하지 않고 진입·저장을 차단합니다.
